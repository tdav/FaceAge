# FaceAge

Android-приложение на .NET MAUI (.NET 11): оценивает возраст по лицу с фронтальной камеры. Всё считается на телефоне, без сети.

- **Камера** — CameraX: превью и поток кадров RGBA, анализируется только последний кадр.
- **Лицо** — YuNet (ONNX): рамка и точки глаз, носа, рта. **Возраст** — InsightFace genderage (ONNX) по кропу, выровненному по глазам, и его зеркальной копии; затем поправка систематической ошибки модели. ONNX Runtime на CPU.
- **Кадры** — размытые, тёмные, пересвеченные, мелкие и повёрнутые в оценку не идут (на экране — подсказка); показывается медиана годных кадров за 3 с.
- **Дизайн** — токены «Chrono Business - Apple Design»: карточка `glass-opaque`, Inter, акцент Material You на Android 12+.

## Точность

Замер на UTKFace (`tools/AgeEval`, поправка подбиралась на одной половине фото и проверялась на другой):

| Возраст | Без поправки, MAE | С поправкой, MAE |
|---|---|---|
| 13–19 | 14,8 | 10,9 |
| 20–29 | 7,6 | 4,0 |
| 30–40 | 8,3 | 6,8 |
| 13–40 | 8,5 | 5,7 |
| все (1–99) | 10,2 | 8,5 |

Ограничения: подростков модель почти не отличает от взрослых 20–25 лет; наклон головы компенсируется лишь частично (точки глаз YuNet грубые). На камере телефона точность не измерялась — UTKFace снят иначе.

Повторить замер (набор UTKFace скачивается отдельно, файлы `<номер>_<возраст>.jpg`):

```bash
dotnet run --project tools/AgeEval -c Release -- "папка1;папка2" 0 raw.csv
python -I tools/AgeEval/fit_calibration.py raw.csv 1 99
```
## Подготовка

Модель возраста и тестовые фото не хранятся в репозитории по условиям их лицензий — скачайте их один раз:

```powershell
./fetch-assets.ps1
```

## Сборка

```bash
dotnet build src/FaceAge/FaceAge.csproj -c Debug -t:Install   # Debug на эмулятор или телефон
build-apk.bat                                                 # Release APK (arm64), подписанный SataKeyStore
```

`build-apk.bat` спрашивает псевдоним ключа и пароль (или берёт `FACEAGE_KEY_ALIAS`, `FACEAGE_STORE_PASS`, `FACEAGE_KEY_PASS`). Готовый файл — `dist/com.sata.faceage-Signed.apk`.

## Тесты

```bash
dotnet test --project tests/FaceAge.Tests/FaceAge.Tests.csproj
```

Тесты прогоняют `AgeEstimator` из приложения на двух фото во всех поворотах кадра камеры, проверяют отбраковку испорченных кадров, поправку возраста и медиану по кадрам (`AgeWindow`).
