# FaceExport — экспорт лиц из Oracle для обучения

Программа Windows Forms. Для каждого сочетания «возраст × пол» выполняет ваш SQL-запрос, читает фото из базы по одному, находит лицо тем же кодом, что в приложении FaceAge, вырезает 256×256 и записывает в папку экспорта. Папка потом идёт на обучение модели возраста. Формат папки описан в разделе 4 документа `docs/superpowers/specs/2026-11-12-age-training-design.md`.

Программа только читает базу. Рекомендуется учётная запись Oracle с правом только на чтение.

## Сборка

На компьютере разработчика, из корня репозитория:

```
dotnet publish tools/FaceExport/FaceExport.csproj -c Release -o dist/FaceExport -p:RestoreIgnoreFailedSources=true
```

Параметр `RestoreIgnoreFailedSources` нужен, когда нет доступа к nuget.org и пакеты берутся из локального кэша.

На сервер копируется вся папка `dist\FaceExport` целиком (около 140 МБ): в ней `FaceExport.exe`, папка `Models` с двумя моделями, `onnxruntime.dll` и четыре библиотеки VC++ (`msvcp140.dll`, `msvcp140_1.dll`, `vcruntime140.dll`, `vcruntime140_1.dll`).

## Требования к серверу

- Windows Server 2016 или новее (x64) рекомендуется; .NET 10 поддерживает и Windows Server 2012, и Windows 10 версии 1607 и новее.
- Ставить .NET и VC++ не нужно: всё лежит в папке программы.
- Сетевой доступ к серверу Oracle и право записи в папку экспорта.
- Свободное место на диске экспорта: каждое фото — один JPEG 256×256; после пробного прогона по размеру папки можно оценить весь диапазон.

## Первый запуск

1. Запустить `FaceExport.exe`.
2. Заполнить сервер в виде `host:port/service`, пользователя и пароль. Пароль вводится при каждом запуске и нигде не сохраняется.
3. Проверить SQL-запрос. Он должен содержать параметры `:age` и `:sex` и возвращать три поля по порядку: фото (BLOB), дата рождения, дата съёмки.
4. Указать значения `:sex` через `;` так, как они записаны в вашей базе (например `M;F`).
5. Указать папку экспорта на диске с достаточным местом.
6. Первый прогон — один возраст: поставить «от» и «до» одинаковыми, например 27 и 27. Нажать «Старт».
7. Когда пары закончатся, открыть папку `images\27\` и посмотреть несколько лиц: лицо по центру, глаза на одной линии, это действительно тот возраст.
8. Только после этого выставить весь диапазон (по умолчанию 10–55) и нажать «Старт» снова. Уже выгруженные пары пропускаются.

«Стоп» дожидается конца текущего фото. Незаконченная пара при следующем запуске выгружается заново: её строки и файлы удаляются, в журнале будет строка «Удалено N строк незавершённой пары». Закрытие окна во время работы действует так же, как «Стоп».

Настройки, кроме пароля, запоминаются в `%AppData%\FaceExport\settings.json`.

## Если что-то пошло не так

- Сообщение «Поле 1 должно быть фото (BLOB), а пришло …», «Поле 2 …», «Поле 3 …»: запрос возвращает поля не в том порядке или не тех типов. Поля по порядку: фото, дата рождения, дата съёмки. Поправить SELECT.
- Строка журнала «ВНИМАНИЕ: пропущена большая доля фото» (больше 10 % пропущено): в скобках указаны причины — «не открылось», «лицо не найдено», «даты или фото пустые». Посмотреть, что это за фото, до того как выгружать весь диапазон.
- «В базе нет фото» для пары: запрос ничего не вернул; проверить значение пола и условия возраста.
- Ошибка подключения: проверить `host:port/service`, имя и пароль. Таймаут подключения — 15 секунд.
- Сообщение о папке, созданной с другими параметрами: в этой папке уже лежит `export.json` с другими настройками вырезания. Выбрать новую папку.
- Не найден файл модели: рядом с `FaceExport.exe` должна быть папка `Models` с `yunet_320.onnx` и `genderage.onnx`.

## Для старой базы Oracle

Драйвер по умолчанию — `Oracle.ManagedDataAccess.Core` 23.26.400. Для старых версий базы пересобрать с другим драйвером:

```
dotnet publish tools/FaceExport/FaceExport.csproj -c Release -o dist/FaceExport -p:RestoreIgnoreFailedSources=true -p:OracleDriverVersion=3.21.120
```

Нужная версия пакета должна быть доступна в кэше NuGet или на nuget.org.

## Не проверено на настоящей базе

Настоящей базы Oracle при разработке не было. Цикл чтения проверен на SQLite через тот же интерфейс ADO.NET; всё, что связано именно с драйвером Oracle, впервые проверяется на вашем сервере.

- Чтение BLOB. Код ждёт, что драйвер вернёт фото как `byte[]`. Если придёт `OracleBlob`, программа остановится с сообщением «Поле 1 должно быть фото (BLOB), а пришло OracleBlob»; исправление — читать через `GetOracleBlob(0).Value`.
- Отмена долгого запроса. «Стоп» вызывает `Cancel()` у команды; как быстро драйвер прервёт тяжёлый запрос на стороне базы, не проверено.
- Версия драйвера. Работа с драйвером 23.26.400 на вашей версии Oracle не проверена; при проблемах с подключением попробуйте драйвер 3.21.120 (см. выше).
- Привязка параметров по имени включена (`BindByName`); без неё `:age` и `:sex` привязались бы по порядку.
