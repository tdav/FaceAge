# Обучение модели возраста FaceAge

Эта папка обучает нейросеть, которая по фотографии лица определяет возраст. На входе — папка с вырезанными лицами, которую делает программа FaceExport. На выходе — файл `model.onnx` и отчёт о точности. Обучение запускается на компьютере с видеокартой NVIDIA. Python знать не нужно: достаточно набирать команды по порядку.

Две модели обучаются отдельно, одна за другой:

- `small` — доработка нынешней модели приложения. В приложении меняется только файл.
- `large` — более крупная сеть. Обычно точнее, но в приложении нужны небольшие правки (размер входа и имя выхода).

## 1. Что нужно

- Windows 10 или 11.
- Видеокарта NVIDIA и свежий драйвер (проверка: в командной строке команда `nvidia-smi` выводит таблицу с названием карты).
- Python 3.13 (с сайта python.org; при установке отметить «Add python.exe to PATH»).
- Около 10 ГБ свободного места на диске для пакетов и результатов.
- Папка экспорта, которую сделал FaceExport (внутри `export.json`, `metadata.jsonl`, папка `images`).

## 2. Что перенести с компьютера разработчика

1. Папку `tools\train` целиком (в ней `train.py`, `dataset.py`, `models.py`, `requirements.txt`, этот файл). Пусть она будет `C:\FaceAge\train`.
2. Файл `src\FaceAge\Resources\Raw\genderage.onnx`. Положить рядом: `C:\FaceAge\genderage.onnx`.
3. Папку экспорта целиком, например в `C:\FaceAge\export`. Она большая; копировать её нужно вместе с `images`.

Пути ниже даны для такого расположения. Если у вас другие, подставьте свои.

## 3. Установка (один раз)

Все команды вводятся в PowerShell. Открыть: Пуск, набрать `PowerShell`.

**Шаг 1. Перейти в папку и создать окружение Python.**

```powershell
cd C:\FaceAge\train
python -m venv C:\FaceAge\venv
```

Должно получиться: команда завершается без сообщений, появляется папка `C:\FaceAge\venv`.

**Шаг 2. Поставить PyTorch под свою видеокарту.** Это делается отдельно, до остальных пакетов, потому что обычная сборка не умеет работать с видеокартой. Нужны версии `torch==2.14.1` и `torchvision==0.29.2`. На 2026-11-12 для них есть две сборки: `cu126` и `cu130`. Какую взять, подсказывает страница https://pytorch.org/get-started/previous-versions/ (искать версию 2.14.1) и драйвер: `cu130` требует очень свежего драйвера, `cu126` подходит большинству. Команда для `cu126`:

```powershell
C:\FaceAge\venv\Scripts\python.exe -m pip install torch==2.14.1 torchvision==0.29.2 --index-url https://download.pytorch.org/whl/cu126
```

Для `cu130` в конце адреса вместо `cu126` написать `cu130`. Должно получиться: в конце строка `Successfully installed torch-2.14.1+cu126 ...`.

**Шаг 3. Поставить остальные пакеты.**

```powershell
C:\FaceAge\venv\Scripts\python.exe -m pip install -r requirements.txt
```

Должно получиться: `Successfully installed ...` без красных ошибок. Версии в файле зафиксированы, менять их нельзя. Пакеты `torch` и `torchvision` уже стоят, они не будут заменены.

**Шаг 4. Проверить, что видеокарта видна.**

```powershell
C:\FaceAge\venv\Scripts\python.exe -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```

Должно получиться: `True` и название вашей видеокарты. Если напечатано `False`, обучение пойдёт на процессоре в десятки раз медленнее: останавливайтесь и переустанавливайте PyTorch из шага 2 (скорее всего, поставилась сборка без CUDA или не подошла сборка под драйвер).

## 4. Обучение

Сначала `small`. Запускайте из папки `C:\FaceAge\train`.

```powershell
C:\FaceAge\venv\Scripts\python.exe train.py --data C:\FaceAge\export --genderage C:\FaceAge\genderage.onnx --model small --out C:\FaceAge\runs\small
```

Затем `large`. При первом запуске нужен интернет: программа один раз скачивает готовые стартовые веса сети (около 20 МБ), дальше они берутся из кэша.

```powershell
C:\FaceAge\venv\Scripts\python.exe train.py --data C:\FaceAge\export --genderage C:\FaceAge\genderage.onnx --model large --out C:\FaceAge\runs\large
```

Что должно получиться:

- В начале программа печатает число фото для обучения и для проверки, затем строку `Сверка pred: ...` (см. раздел 6).
- После каждой эпохи печатается строка вида `Эпоха 3/30: потеря 6.2, MAE clean 5.1, MAE phone 6.0, 95 с`. Эпох по умолчанию 30. MAE должна в целом уменьшаться.
- В конце печатается `Готово: C:\FaceAge\runs\small`.

Одна эпоха на видеокарте занимает от десятков секунд до нескольких минут, в зависимости от числа фото и карты. Окно закрывать нельзя. Можно остановить обучение клавишами Ctrl+C и продолжить позже (раздел 8).

## 5. Как читать отчёт

В папке результата (`C:\FaceAge\runs\small`) появятся файлы. Откройте `report.md` любым редактором (блокнот подойдёт).

Все цифры считаются по фото, которые модель никогда не видела при обучении (15 % от всех), для возрастов 13–50 лет. Модель смотрит на фото и на его зеркальное отражение и берёт среднее, как в приложении.

**Главная цифра** — таблица «Сводка», строка «обученная», режим **phone**, столбец **MAE**. MAE — средняя ошибка в годах: на сколько лет в среднем модель ошибается. Чем меньше, тем лучше. Режим `phone` — фото с искажениями, как на камере телефона (лёгкое размытие, шум, сжатие), поэтому он ближе к жизни. Режим `clean` — фото без искажений, смотрите его как дополнительный.

Что сравнивать в той же таблице:

- «исходная» — нынешняя модель приложения, без поправок.
- «исходная с поправкой» — она же с поправочной таблицей, как работает приложение сейчас. **Это то, что нужно побить**: обученная модель имеет смысл, если её MAE в режиме `phone` ниже, чем у этой строки.
- «обученная» — новая модель.

Дополнительно:

- «Смещение» — завышает или занижает возраст в среднем. Плюс — завышает, минус — занижает. Хорошо, когда близко к нулю.
- Столбцы ≤1, ≤2, ≤3, ≤5 — доля фото, где ошибка не больше этого числа лет.
- Таблицы «по годам» показывают, на каких возрастах модель ошибается сильнее.
- В конце отчёта есть «Расхождение ONNX Runtime с PyTorch». Должно быть меньше 0,01 года (обычно порядка 1e-5). Если больше, `model.onnx` нельзя использовать, сообщите разработчику.

## 6. Предупреждение «Сверка pred»

Каждое фото в экспорте несёт поле `pred`: возраст, который дала на нём нынешняя модель приложения. Перед обучением программа заново считает этот возраст на своей подготовке фото и сравнивает с `pred`. Если подготовка такая же, как в приложении, числа почти совпадают.

Строка `Сверка pred: ... в норме` означает: всё хорошо.

Строка `ПРЕВЫШЕН ПОРОГ` и рамка из восклицательных знаков означает: программа готовит фото не так, как приложение. Обучение на таких данных даст модель, которая в приложении будет работать хуже, чем показывает отчёт. Что делать: не использовать результат, прислать разработчику строку сверки и первые строки `export.json`. Обычная причина: экспорт сделан другой версией FaceExport или фото повреждены.

## 7. Что принести обратно

Из каждой папки результата (`small` и `large`) три файла:

- `model.onnx` — обученная модель (лучшая по режиму `phone` эпоха);
- `report.md` — отчёт;
- `report.json` — те же цифры для программ.

Остальные файлы (`best.pt`, `last.pt`) большие и разработчику не нужны.

## 8. Если что-то пошло не так

**Не хватает памяти видеокарты** (в ошибке есть `CUDA out of memory`). Уменьшите размер пакета: добавьте в конец команды `--batch 64`, а если не помогло — `--batch 32`. Другие параметры не менять. Для `large` пакет по умолчанию тяжелее, чем для `small`, поэтому ошибка чаще возникает на нём.

**Обучение прервалось** (выключили компьютер, нажали Ctrl+C, ошибка). После каждой эпохи программа сохраняет `last.pt`. Повторите ту же команду с добавлением `--resume` в конце, с тем же `--out`:

```powershell
C:\FaceAge\venv\Scripts\python.exe train.py --data C:\FaceAge\export --genderage C:\FaceAge\genderage.onnx --model small --out C:\FaceAge\runs\small --resume
```

Должно получиться: строка `Продолжение с эпохи N`, и обучение идёт дальше с места остановки. Остальные параметры (`--epochs`, `--batch` и т. д.) оставляйте теми же, что в первом запуске, кроме `--batch`, если причина была в памяти.

**Сообщение «В отложенной части нет фото 13–50 лет»** — в экспорте нет нужных возрастов. Нужен другой экспорт.

**Быстрая проверка, что всё работает**, без полного обучения: добавьте `--epochs 1 --limit 600`. Программа обучится на 600 фото за минуту и проверит весь путь до `model.onnx`; точность при этом не важна.
